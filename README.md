## 🛠️ How to Install

1. Install the [Tampermonkey Extension](https://tampermonkey.net) for your browser.
2. In the table above, find the script you want and click the **[Install]** link.
3. Tampermonkey will open an installation prompt automatically. Click **Install**.
4. Refresh the target website to see the script in action.

## 🗂️ Adding New Scripts (For the Developer)
To add a new script to this collection:
1. Create a new file in this repository ending in `.user.js`.
2. Ensure it has a unique `// ==UserScript==` header block.
3. Sync the raw URL of the new file to your Greasy Fork account.
